## 2. 自动编号机制

### 2.1 章节编号

章节编号通过 Word 多级列表（numId=1）自动生成，各级标题挂对应的 ilvl。用户在 Word 中增删章节时，编号自动重排。

层级格式：
```
1              （Heading 1, 第1章）
1.1            （Heading 2）
1.1.1          （Heading 3）
1.1.1.1        （Heading 4）
```

### 2.2 图编号（按节编号）

默认规则为 `节号-序号`。第一个编号使用图片所在章节向上追溯到的最近二级标题编号；第二个编号在该二级节内独立递增。例如 `3.1` 节中的第 1 张图为 `图3.1-1`。

插入图时使用下列域代码：

```
图 { STYLEREF 2 \s }-{ SEQ Figure \* ARABIC \s 2 } { 标题文字 }
```

其中 `STYLEREF 2 \s` 获取 Heading 2 的编号，`SEQ Figure \s 2` 保证图片序号在每个二级节内重置。用户增删图片后，文档打开时自动更新域；如未刷新，可执行 Ctrl+A → F9。

### 2.3 表编号（按节编号）

表编号采用与图编号相同的前缀规则，但表序号独立递增。例如 `3.1` 节中的第 1 个表为 `表3.1-1`。

插入表时使用下列域代码，标题置于表格上方：

```
表 { STYLEREF 2 \s }-{ SEQ Table \* ARABIC \s 2 } { 标题文字 }
```

### 2.4 交叉引用

正文中引用图/表时使用 Word REF 域：

```
如图 { REF Figure_1 } 所示
见表 { REF Table_1 }
```

这样当图/表编号变化时，正文引用同步更新。

### 2.5 目录

TOC 域，取 Heading 1~3 级：

```
TOC \o "1-3" \h \z \u
```

目录标题“目  录”使用黑体 16pt，水平居中，无首行缩进。目录条目使用宋体 12pt，无首行缩进；一级条目左缩进 0，二级条目按层级少量左缩进。用户在 Word 中按 Ctrl+A → F9 刷新目录页码和标题。

### 2.6 图片内版式默认规则

| 参数 | 默认值 |
|---|---|
| 插入宽度 | 14cm，高度按原始比例缩放 |
| 图片画布 | PNG，宽度 2160px，约 392DPI；高度按内容确定 |
| 关键词/标题 | 小四，12pt，深灰蓝文字 |
| 说明文字 | 五号，10.5pt，中灰蓝文字 |
| 文字分组 | 每个图元内的标题和说明作为一个整体文本块 |
| 水平对齐 | 文本块水平居中；多行文字逐行居中 |
| 垂直对齐 | 文本块在所在图元内垂直居中，禁止标题固定贴顶 |
| 默认底色 | 白色画布 |
| 图元底色 | 浅蓝、深浅灰、白色；蓝色标识主链路或重点层，灰色标识支撑层或容器 |
| 边框与箭头 | 中灰蓝单线，统一圆角矩形和统一箭头 |
| 禁用配色 | 红、橙、黄、绿、紫等装饰色；不允许一张图内出现多种语义不明的色系 |
| 最小留白 | 文字与图元边界的实际间距不小于 6px，图元之间保留明显空白 |
| 渲染质量 | 不低于 300DPI，默认 392DPI |

生成后必须通过机器质检；任何一项失败都不得插入 Word：

| 检查项 | 通过条件 |
|---|---|
| 非空白 | 图像存在有效内容 |
| 内容密度 | 无大面积空置，也无过密拥堵 |
| 蓝灰配色 | 非蓝/灰/白/黑色像素比例不超过 0.2% |
| 图元重叠 | 图元只允许包含或分离，不允许局部压叠 |
| 文字出界 | 文字外接框必须落在所属图元安全区内 |
| 文字重叠 | 任意文字外接框互不重叠 |
| 水平居中 | 文本块中心与图元水平中心偏差不超过 2px |
| 垂直居中 | 文本块中心与图元垂直中心偏差不超过 2px |
| 字号一致性 | 按 14cm 落版宽度换算后，标题 12pt，说明 10.5pt |

### 3.4 自定义模板文件解析

用户上传自己的 .docx 模板后，系统自动解析以下信息：

| 解析项 | 提取内容 | 用途 |
|---|---|---|
| styles.xml | 所有样式名称、字体、字号、加粗、编号、大纲级别 | 映射到输出的 Heading/正文/图表标题 |
| numbering.xml | 多级列表编号定义 | 确定章节编号格式 |
| document.xml 的 sectPr | 页面尺寸、边距、页眉页脚设置 | 应用页面设置 |
| header/footer XML | 页眉页脚内容 | 应用页眉页脚 |
| TOC 域 | TOC 级别范围 | 配置目录 |

解析结果展示给用户确认："检测到您的模板包含以下样式，是否按此输出？"

## 4. 转换链集成

格式配置在 merge → verify → convert 管道中的挂载点：

```
merge（分章→整册 MD）
   ↓
verify（内容校验，与格式无关）
   ↓
convert（MD→docx，此步骤读取格式配置）
   │
   ├── 读取格式配置集（页面/标题/正文/图表/列表/页眉页脚/封面）
   ├── 加载对应 docx 模板（默认模板或用户上传模板）
   ├── 生成样式定义（styles.xml）
```

## 5. 注意事项

1. 默认文档设置 `updateFields=true`，SEQ 域在 Word 打开时自动刷新；如用户关闭该提示，可执行 Ctrl+A → F9。
2. 用户上传的模板如果缺少 Heading 样式的编号链，convert 需要自动补建（或提示用户模板不完整）。
3. 目录页码在 convert 生成时是占位值，用户在 Word 中刷新 TOC 后才显示真实页码。
4. 按节编号由 `SEQ ... \s 2` 结合 Heading 2 完成，禁止在正文中写入静态图表编号。
