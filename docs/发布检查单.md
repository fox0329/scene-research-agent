# 场景通 发布检查单（每次发版逐项打勾）

> 目的：把「能跑」变成「可发布」。任何一项没勾，不发版。
> 发布由 **一个平台一个人** 执行完整流程；另一平台只做安装验收。

## 一、代码与版本

- [ ] `main` 全绿：`npx vitest run`（当前基准 97 文件 / 1,900+ 例）
- [ ] E2E 全绿：`npx playwright test`（当前基准 42 例；改过 UI 必须重跑）
- [ ] 类型检查：`npx tsc -b packages/contract packages/infra apps/server apps/web`
- [ ] 文档表同步：`node scripts/gen-table-docs.mjs --check`
- [ ] 版本号一致：根 `package.json` = `apps/desktop/package.json` = 安装包版本
- [ ] `docs/项目变更表.md` 已登记本版全部用户可见变更

## 二、本机安装包验收（macOS arm64）

- [ ] `bash scripts/build-release.sh` 或 `pnpm build` + `pnpm --filter @scene/desktop run pack:mac:arm64` 出包
- [ ] 删掉 `/Applications/场景通.app` 后全新安装，能启动、端口只监听 `127.0.0.1`
- [ ] 设置 → 模型配置：填端点/Key → 测试连接成功 → 设为默认
- [ ] 新建场景 → 跑完第 1 步（有真实来源链接）→ 右栏来源可点开
- [ ] 资料库：导入 1 个 PDF/DOCX → 回执有质量行 → 体检按钮可用
- [ ] 交付物：生成 → 导出 Word / Markdown（PPT 需本机 Python）
- [ ] 设置 → 数据备份：立即备份成功、列表出现、恢复提示重启
- [ ] 诊断导出：能下载/保存诊断文件，内容含版本与最近日志
- [ ] 覆盖安装（旧版→新版）：数据、模型配置、历史场景都在

## 三、Windows x64 验收（在 Windows 机器上做）

- [ ] `pnpm --filter @scene/desktop run pack:win:x64` 出 setup 与 portable
- [ ] 安装版：非管理员安装、桌面/开始菜单快捷方式、卸载保留数据
- [ ] 免安装版：解压即用、数据同样落在 `%APPDATA%\@scene\desktop`
- [ ] 中文用户名/中文路径下启动正常；SQLite 原生模块加载正常
- [ ] SmartScreen 提示「仍要运行」可继续；密钥可保存并重启后仍可用
- [ ] 从旧版覆盖升级：数据与配置保留

## 四、发布

- [ ] 打 tag：`git tag vX.Y.Z && git push origin vX.Y.Z`
- [ ] GitHub Actions 两平台 job 全绿（含打包产物冒烟）
- [ ] Release 资产齐全：mac dmg、win setup、win portable、`SHA256SUMS.txt`
- [ ] 用 `SHA256SUMS.txt` 抽验一个下载文件
- [ ] 发布说明包含：下载哪个、首次放行、Python 前提、数据目录、升级前备份、已知限制
- [ ] 转存百度网盘（给不能访问 GitHub 的用户）

## 五、已知限制（发布说明必须写）

- 免签名：macOS 需右键打开/`xattr`，Windows 需 SmartScreen「仍要运行」
- 仅支持 Apple 芯片 Mac（arm64）与 Windows x64
- 联网调研依赖第三方检索通道，失败时来源会显示「未知」并提示重试
- 证据 B = 有出处可回查，不等于内容已被独立核实
- 长任务耗时：单步分析约 1–3 分钟，交付物生成约 10–20 分钟
