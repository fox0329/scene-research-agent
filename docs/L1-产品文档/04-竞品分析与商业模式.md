# 04 竞品分析与商业模式

## 4.1 市场与客户

### 谁买、谁用

| 角色  | 是谁                     | 关心什么               |
| --- | ---------------------- | ------------------ |
| 使用者 | 解决方案架构师 / 售前方案工程师      | 少加班、少返工、方案能讲、来源站得住 |
| 购买者 | 售前总监 / 解决方案负责人 / 数字化部门 | 团队人效、方案质量一致性、可复用资产 |
| 决策者 | 事业部/公司管理层              | 投入产出、客户响应速度、赢单率    |

### 目标客户类型

1. **系统集成商**：多行业、多产品线，售前团队规模 10–100 人，方案重复度高；
2. **设备/产品厂商的售前部门**：产品资料多，场景跨行业，最需要“产品能力 × 场景”的匹配；
3. **行业解决方案公司/咨询公司**：需要快速判断新场景、输出可讲方案；
4. **大中型企业数字化部门**：内部场景多，需本地化、数据不出内网。

### 购买触发点

- 新行业/新场景拓展，售前人手不够；
- 投标/大客户方案周期紧，返工多；
- 产品资料散、新人上手慢；
- 客户要求“说清依据”，现有方案来源站不住；
- 团队想沉淀可复用的行业/产品资产。

## 4.2 竞品格局（按替代关系分四类）

### 4.2.1 通用大模型 / Deep Research

代表：ChatGPT（含 Deep Research）、Claude、Microsoft Copilot、豆包/通义/文心等。

| 能力      | 表现             | 对场景通的影响              |
| ------- | -------------- | -------------------- |
| 通用调研/写作 | 强，能快速生成分析      | 用户可能觉得“用 ChatGPT 就行” |
| 我方产品知识  | 不懂，需要用户每次贴资料   | 场景通的产品资料库是差异         |
| 结构化流程   | 无，靠用户自己 prompt | 6 步/26 表是差异          |
| 来源可信    | 不稳定，常无出处       | 来源/证据分级是差异           |
| 交付物     | 一段文本，需人工再整理    | 解决方案 + PPT 大纲闭环是差异   |
| 数据      | 云端             | 本地桌面是差异（客户材料敏感时）     |

### 4.2.2 办公/知识库 AI

代表：飞书智能伙伴、Notion AI、钉钉 AI 助理、企业知识库产品。

| 能力      | 表现              | 对场景通的影响           |
| ------- | --------------- | ----------------- |
| 文档检索/问答 | 强               | 解决“找得到”，不解决“该看什么” |
| 流程/表格   | 弱，偏通用           | 场景通的 26 张表是垂直资产   |
| 来源追溯    | 有引用，但不做权威性/证据分级 | 场景通更严格            |
| 交付物     | 不生成售前解决方案       | 场景通闭环更强           |
| 数据      | SaaS 为主         | 本地/私有化是差异         |

### 4.2.3 咨询/行业研究

代表：赛迪顾问、艾瑞咨询、头豹研究院、行业咨询公司。

| 能力     | 表现       | 对场景通的影响           |
| ------ | -------- | ----------------- |
| 行业深度   | 强，有专家与报告 | 场景通不替代深度咨询        |
| 客户场景定制 | 弱，报告通用   | 场景通按客户场景生成        |
| 周期/价格  | 周/月级，费用高 | 场景通是“日常工具”，不是咨询替代 |
| 我方能力匹配 | 通常不含     | 场景通结合产品资料库        |

**定位**：咨询是“深度外包”，场景通是“团队日常提效 + 方案初稿”；可互补，不正面竞争。

### 4.2.4 售前/标书/CRM 工具

代表：销售易、纷享销客、标书制作/查重工具、方案模板库。

| 能力      | 表现  | 对场景通的影响      |
| ------- | --- | ------------ |
| 商机/流程管理 | 强   | 场景通不做 CRM    |
| 标书排版/查重 | 强   | 场景通不做标书排版    |
| 调研与方案内容 | 弱   | 场景通补内容生产     |
| 产品资料库   | 弱/无 | 场景通的产品资料库是差异 |

**定位**：可与 CRM/标书工具集成，不替代。

## 4.3 竞争结论

场景通的差异化不在“模型更强”，而在**垂直流程 + 产品资料库 + 来源可信 + 交付物闭环 + 本地数据**：

1. 通用模型有智力，但没有“售前调研的骨架”和“我方产品底账”；
2. 知识库有资料，但不告诉你“该看什么、看全没有”；
3. 咨询有深度，但贵、慢、不针对具体客户场景；
4. CRM/标书工具有流程，但不生产方案内容。

**风险**：通用模型能力持续增强，会压缩“通用调研/写作”的价值；场景通必须把壁垒放在**垂直数据（产品库/场景资产）、流程标准、证据与交付物**上。

## 4.4 商业模式

### 4.4.1 收费对象

- 首要：售前/解决方案团队（按席位）；
- 其次：企业级私有化部署（按年授权 + 实施/维护）；
- 补充：按项目/按场景的报告包（低频客户）。

### 4.4.2 三种模式对比

| 模式         | 怎么收          | 适合谁         | 优点             | 风险               |
| ---------- | ------------ | ----------- | -------------- | ---------------- |
| A. 团队席位订阅  | 每架构师每月/每年    | 中小售前团队      | 简单、可扩张、与使用频率挂钩 | 客户可能觉得“又一个 SaaS” |
| B. 私有化授权   | 年授权费 + 实施/维护 | 大型企业、客户数据敏感 | 客单价高、粘性强       | 交付重、销售周期长        |
| C. 按项目/场景包 | 每场景/每份报告     | 低频、试用型客户    | 门槛低、易试用        | 收入不稳定、难预测        |

**建议**：先 A 验证付费意愿，B 做高价值客户；C 只作为试用/补充，不做主力。

### 4.4.3 定价原则

- **价值定价**：价格应显著低于客户节省的人天成本（例如不超过年节省成本的 20–30%），让客户算得过账；
- **按席位**：与使用者数量挂钩，简单透明；
- **私有化溢价**：数据不出内网、可接内部模型/知识库，收部署与维护费；
- **不按 token 收费**：售前用户不关心模型成本，按结果/席位更容易理解。

## 4.5 获客与落地路径

1. **内部试点**：先在 1–2 个售前团队用 4 周，记录周期/人天/返工；
2. **案例包**：匿名化 3 个场景的前后对比，形成可转发的案例；
3. **渠道**：厂商售前体系、集成商合作伙伴、行业社群；
4. **产品化**：从“单机工具”到“团队版”（共享产品库/模板/权限）再到“私有化”；
5. **服务**：轻咨询（场景梳理/模板定制）带动订阅。

## 4.6 壁垒与风险

**壁垒**：

- 垂直流程与 26 张表的领域资产（不是通用 prompt）；
- 产品资料库与历史场景资产（越用越厚）；
- 来源/证据/质量门禁形成的可信度；
- 本地化部署能力（客户材料不出内网）。

**风险**：

- 通用模型能力提升，压缩“通用调研”价值；
- 客户不愿为“工具”付费，除非能证明人效/赢单；
- 模型/检索成本与稳定性；
- 售前流程非标，产品需要行业模板；
- 数据安全与合规（客户材料、模型调用）。
