# 场景通 0.2.1 安装说明

> 一个桌面应用：把「这场景能不能进、怎么进、值不值」的调研，从几周压到几天。
> 数据全部存在你自己电脑上，不上传任何服务器。

---

## 一、先看你的电脑，下载对应那个文件

| 你的电脑 | 下载这个文件 |
|---|---|
| Mac（M1 / M2 / M3 / M4 等 Apple 芯片） | `SceneMaster-0.2.1-mac-arm64.dmg` |
| Windows 10 / 11（64 位） | `SceneMaster-0.2.1-win-x64-setup.exe`（**安装版，推荐**）<br>或 `SceneMaster-0.2.1-win-x64-portable.exe`（免安装，解压即用） |

**注意**：暂不支持较老的 Mac（Intel 芯片机型）。

---

## 二、Mac 安装（两步）

1. 双击 dmg，把「场景通」图标**拖进「应用程序」文件夹**
2. 第一次打开如果提示「无法验证开发者 / 已损坏」：
   - 打开 **系统设置 → 隐私与安全性**，往下翻，点 **「仍要打开」**
   - 或者打开「终端」，粘贴这一行回车即可：

     ```bash
     xattr -dr com.apple.quarantine /Applications/场景通.app
     ```

---

## 三、Windows 安装

- **安装版（setup）**：双击一路「下一步」装完
- **免安装版（portable）**：解压到任意文件夹，双击里面的 exe 直接用
- 如果弹出「**Windows 已保护你的电脑**」：点 **更多信息 → 仍要运行**
  （这是未购买微软签名证书的正常提示，不是病毒）

---

## 四、想让「导出 PPT」也能用（可选）

导出 PPT 需要电脑里有 **Python 3.10 或更高版本**；**没有也不影响**分析和导出 Word / Markdown。

- Mac：终端执行 `brew install python3`
- Windows：到 <https://www.python.org/downloads/> 下载安装，安装时勾选
  **“Add python.exe to PATH”**

---

## 五、升级前请先备份（重要）

你的数据（场景、材料库、交付物）都在这里，**覆盖安装不会动它们**，但升级前建议整份拷贝留底：

- Mac：`~/Library/Application Support/@scene/desktop/data/`
- Windows：`%APPDATA%\@scene\desktop\data\`

---

## 六、第一次使用三步

1. 打开「**设置**」，填模型服务商的 API Key（或本地服务地址）
2. 建一个**产品资料库**，上传我方材料（产品资料、能力清单、案例）
3. **新建场景** → 客户材料入库 → 对话把场景定义清楚 → 按 7 步推进 → 最后在「交付物」导出 Word / PPT / Markdown
