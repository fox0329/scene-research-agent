Token 本地扩展均已写入 `apps/web/src/styles/tokens.css` 并带用途注释；登记于 `docs/项目变更表.md` #12。

## 三、豁免清单（登记不修）

| # | 豁免项 | 理由 |
|---|---|---|
| E1 | `@media (max-width: 1320px / 940px)` 断点裸值 | CSS 变量不能用于媒体查询；两值即 design-system 登记的断点 Token 值，仅表达方式受限 |
| E2 | `prefers-reduced-motion` 块内 `0.01ms !important` 重置 | 无障碍标准手法，非设计值 |
| E3 | 渐隐遮罩 `mask-image: … #000 14px` | 遮罩通道黑色表"不透明"，非视觉颜色 |
| E4 | `border-bottom: 2px solid transparent`（Tab 占位下划线） | 边框宽度不在视觉值 Token 清单内，且为透明占位 |
| E5 | `box-shadow: 0 0 0 2px var(--cp-s)` 类焦点外圈 | 几何扩散宽度，颜色已 Token 化 |
| E6 | 表格容器、列宽拖拽 | 已批准偏离，见变更表 #1/#2 |
| E7 | Token 简名体系（`--s2/--cp/--r8` 对应 design-spec `--space-2/--color-primary/--radius-md`） | 继承原型模板实测血缘，语义一一对应；全量改名收益低、回归风险高 |
| E8 | 交互原型 v9/v10 的 57 项自检差异 | 原型定位＝交互行为验证（产品定义已定性），不随附交付 |
| E9 | JS 动态列宽（`style.width` px 数值） | 列宽拖拽功能的运行时状态，边界值走 min/max 约束 |

## 四、复核方式

```bash
# app.css 字面量残留扫描（应只剩 E4 一行）
grep -nE "(margin|padding|gap|border-radius|width|height|outline|z-index|box-shadow)[^:]*:[^;]*[0-9]+px" \
  apps/web/src/styles/app.css | grep -vE "var\(--|@media|: 1px|mask-image|0 0 0 2px"
# 构建回归
pnpm --filter @scene/web exec vite build
```
