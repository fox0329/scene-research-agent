# 场景通 · L1 Demo 分镜脚本（无声版，8 段）

> 用途：基于真实产品界面生成 3–5 分钟 Demo 视频，**不加配音**，只加字幕/少量动效。
> 总时长：4 分 40 秒；每段 ≤60 秒，便于分段生成后拼接。
> 画幅：1920×1080，30fps，H.264，无音轨。
> 演示项目：`智慧教室`（已完成 6 步，解决方案 + PPT 大纲已生成）；新建场景用 `智慧会议室演示`。
> 原则：不出现真实客户名、金额、API Key；AI 生成过程可加速，但不伪造操作结果。

## S1｜痛点开场（0:00–0:40，40s）

**画面**

- 0–5s：产品首页，鼠标停在「新建」按钮，不点击。
- 5–20s：画面压暗，叠三组关键词字幕（不要做花哨动画）：
  - `材料散：邮件、网盘、聊天记录`
  - `维度漏：合规、竞争、交付边界`
  - `来源虚：客户一问数字，答不上来`
- 20–32s：恢复首页，镜头轻推（scale 100%→103%），突出「场景通」标题。
- 32–40s：黑底白字一行：`把售前调研，从几周压到几天`。

**字幕（不配音）**

> 接到一个新场景，最花时间的不是写方案，是找资料。
>
> 该看什么、看全没有、依据在哪——往往要一两周。

**声音**：无。可留极轻的界面点击音效，但不要背景音乐压字。

**转场**：S1 末尾淡出到黑，S2 从黑淡入。

**验收**：观众 10 秒内知道“这是给售前架构师的调研工具”，不是通用聊天。

## S2｜场景通定位（0:40–1:10，30s）

**画面**

- 0–8s：产品首页 → 鼠标依次掠过「产品资料库」「场景」「设置」，不点开。
- 8–20s：叠一张 3 行结构图（可用简单文字卡，不用真架构图）：
  - `资料库：产品能力/边界/案例`
  - `6 步：从场景定义到交付物`
  - `26 张表：结构化、可溯源`
- 20–30s：回到首页，出现产品一句话：`桌面 AI 智能体 · 售前调研与方案生成`。

**字幕**

> 场景通，一个桌面 AI 智能体。
>
> 结合公司产品资料，把售前调研拆成 6 步分析、26 张信息表，最后产出解决方案和 PPT 大纲。

**转场**：直接切 S3。

**验收**：说清“桌面、AI 智能体、6 步/26 表、解决方案+PPT 大纲”。

- 10–16s：返回场景列表，点「新建」。
- 16–25s：输入场景名 `智慧会议室演示`，光标停在输入框，不急着提交。

**字幕**

>

**操作要点**：不要展示真实产品价格、客户合同、认证编号；列表可打码或只拍标题。

**转场**：点击“创建”后切 S4。

## S4｜AI 场景定义（1:35–2:15，40s）

**画面**

- 0–8s：场景定义弹窗打开，AI 开场白出现（提前准备好，避免等模型）。
- 8–20s：AI 提问“客户是谁、覆盖什么”；用户输入一句 `企业总部办公楼的中小型会议室`。

- 30–40s：镜头停在“场景边界”一行，叠字幕：`不是先填 26 张表，是 AI 先理解，再让用户确认`。

**字幕**

**字幕**

>
> 每条结论可点开来源；查不到就写“未知”。

**操作要点**：不要逐格展示全部 26 张表，选 2 个代表步骤；来源面板必须真实可点。

## 二、生成与拼接说明

### 单段生成

- 每段单独录屏/截图，严格 ≤60 秒；
- 统一 1920×1080、30fps、H.264、无音轨；
- 字幕烧录在画面底部安全区（距底 ≥80px），不要遮挡按钮；
- 文件名：`S01.mp4` … `S08.mp4`。

### 拼接

```bash
# 生成 concat 列表
for f in S0{1..8}.mp4; do echo "file '$PWD/$f'" >> concat.txt; done
ffmpeg -f concat -safe 0 -i concat.txt -c copy 场景通-L1-Demo-无声版.mp4
```

如果各段编码参数不一致，先统一转码：

```bash
ffmpeg -i S01.mp4 -vf scale=1920:1080,fps=30 -c:v libx264 -pix_fmt yuv420p -an S01-n.mp4
```

### 字幕

- 中文字体：`PingFang SC` / `Noto Sans CJK SC`；
- 字号 30–34px，白字 + 半透明黑底；
- 每屏最多 2 行，单行 ≤18 个汉字；
- 不做逐字动画，不做花字。
