# 数据与隐私说明

> 面向使用者与安全评审。一句话：**数据只在本机，出网的只有你配置的模型请求与检索请求。**

## 一、数据存在哪

| 内容 | 位置（macOS / Windows） |
|---|---|
| 业务数据库 | `~/Library/Application Support/@scene/desktop/data/scene.db` / `%APPDATA%\@scene\desktop\data\scene.db` |
| 交付物 | 同目录 `deliverables/` |
| 导出文件 | 同目录 `exports/` |
| 日志 | 同目录 `logs/server.log`、`boot.log` |
| 模型与检索配置 | 同目录 `data/providers.local.json` |

卸载应用不会自动删除上述目录；需要彻底清除时手动删除整个应用数据目录。

## 二、什么会出网

1. **模型调用**：只发往你在「设置」里填的 OpenAI 兼容端点；
2. **联网调研**：发往配置的检索服务（政府/媒体网页抓取），抓到的正文会缓存在本地 `web_source`；
3. **没有遥测**：不上报使用行为、崩溃、场景内容；没有账号体系。

材料原文、场景数据、交付物**不会**上传到任何我们控制的服务器（我们也没有服务器）。

## 三、密钥怎么存

默认：明文写入 `data/providers.local.json`，文件权限 `0600`（仅当前用户可读）。
可选：设置环境变量 `SCENE_KEYCHAIN_PROTECTION=1` 后，用系统能力（macOS 钥匙串 / Windows DPAPI）派生密钥，再用 AES-256-GCM 加密落盘。

**风险提示**：默认模式下，能读到该文件的本机用户或备份/同步工具就能读到 Key。共享电脑建议开启系统加密或使用独立低权限账号。

## 四、备份与恢复

本版**不提供内置备份/恢复**。需要保留数据时，请退出应用后手动复制整个应用数据目录（至少 `data/`）；旧版本留下的 `data/backups/` 不会被自动删除。应用自身不会把数据上传到任何服务器。

## 五、日志与诊断

`logs/server.log` 记录启动、迁移、分析进度与错误，不含模型 Key 与完整材料正文。
「设置 → 导出诊断信息」会打包版本、数据目录、迁移记录与最近日志（已做 Key 掩码），用于报障。
