# 场景通 — 开发计划

> **状态**：v1.0（2026-09-22，依据技术方案 v0.3 §十五里程碑展开）
>
> **用法**：任务编号 `M<里程碑>-T<序号>`；状态三档（未开始 / 进行中 / ✅ 完成）；每个里程碑收口跑对应 `verify` 命令，全绿才算达成（技术方案 §十二验收自动化）。计划本身变更走 `docs/项目变更表.md`。
>
> **并行约定**（AGENTS.md 守则）：一任务一 worktree 一分支（`feat/<任务号>-<短名>`）；运行实例端口 4082+、DSH 端口 3082+；`DB_PATH` 指向 worktree 副本。任务表"依赖"列标明先后，无依赖的可并行。
