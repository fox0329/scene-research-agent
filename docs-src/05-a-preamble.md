## 一、通用约定

### 1.1 表的三个级别

| 级别 | 含义 | 用户动作 | 界面 |
|---|---|---|---|
| `重要` | 本阶段要获得的重要信息（结论性事实、结构化可比数据、要拿去汇报的数字） | **逐格校对 / 编辑** | **中栏表格**，默认展开 |
| `支撑` | 支撑性事实（来自材料或检索，供佐证） | 抽查来源，不全看 | 中栏折叠，可展开 |
| `过程` | 推理中间产物与说明类信息 | 不看 | **归右栏阶段总结文档** |

> **本版关键变化**：级别**不再表示"是否需要决策"**——系统不产出任何判定与建议。级别只决定"这条信息显示在中栏表格，还是归右栏总结文档"。

### 1.2 通用列

| 字段 | 中文表头 | 谁生成 | 适用范围 |
|---|---|---|---|
| `source` | 来源 | **模型必填** | 所有 `重要`/`支撑` 表；格式 `文件名:页码` / `文件名#章节` / `URL` / `系统分析:阶段N` |
| `source_type` | 数据来源标记 | **系统自动打标** | 全部表。模型**不生成**此列——模型首次写入= `AI提取`；用户校对未改= `用户确认`；用户新增= `用户补充` |
| `evidence_level` | 证据等级 | 模型 | **仅证据敏感表必填**：表1-2、1-3、2-5、3-1、3-4、3-8。取值 A/B/C/D |
| `authority` | 来源权威性 | 模型 | 同上。取值 T1/T2/T3/T4 |

> **为什么 `source_type` 不由模型生成**：否则模型可能把自己的提取自封为"用户确认"，而 `用户确认` 是 B 级证据的依据。该列必须由系统的写入路径决定。

### 1.2b 栏位分配规则（列预算）

每张表都标注了「栏位分配」，规则如下：

| 规则 | 内容 |
|---|---|
| 中栏列数上限 | **6 列**（目标 4–6）；超出则拆表或把低频列移入右栏 |
| 默认不出现横向滚动 | 正常宽度下按 `table-layout: fixed` + `width: 100%` 分配列宽；**横向滚动仅作极端窄容器下的兜底** |
| 列数 ≤6 是不横滚的前提 | 列数过多 → 每列跌破可读下限（64px）→ 要么内容不可读，要么被迫横滚 |
| 列宽拖拽保留 | 已批准并已实装的功能（变更表 #2 / #19）；机制是"两侧列交换宽度、总宽不变"，**拖拽本身不产生横滚** |
| 降级顺序 | 中栏拖窄时：① 压缩长文本列 → ② 低优先列折叠进右栏 Tab ① → ③ 最后才允许横滚兜底 |
| 行高控制 | 单元格**单行显示**，超约 20 字截断不换行 |
| 长文本 | 超 20 字的字段全文放**右栏 Tab ①（补充说明）**，中栏只显示截断值 |
| 元信息 | `source` / `source_type` / `evidence_level` / `authority` **一律不进中栏**，归右栏 Tab ① |
| 单例信息 | 整表一行时用**纵向「项 / 内容」两列** |
| 宽表拆分 | 业务列 > 6：行粒度不同则拆表；相同则移列入右栏 |

### 1.3 取值铁律（继承 G-R1/G-R2）

- `D` 级内容必须删除或重写；
- `C` 级只能写成假设，**不得作为结论依据**；
- `AI推断` 行**不得作为决策判定输入**，须先进右栏待确认清单转 `用户确认`。

### 1.4 通用枚举

| 枚举名 | 取值 |
|---|---|
| 产品状态 | 在售 / 停售 / 在研 / 规划 / 待确认 |
| 成熟度 | 已交付 / 组件具备 / 在研 / 规划 |
| 实测或宣称 | 实测 / 宣称 / 未提及 |
| 门槛类型 | 技术 / 行业准入 / 经济 / 生态锁定 / 一票否决者 |
| 门槛现状 | 过得了 / 过不了 / 绕道 / 借道 / 等窗口 / 不知道 |
| 处置策略 | 直接进入 / 找替代路径 / 找合作伙伴 / 不进入 / 等政策变化 / 列为调研重点 |
| 我方可参与程度 | 可以碰 / 只能配合 / 不能碰 |
| 匹配判定 | 真能解 / 需补齐 / 不能做 |
| 影响程度 / 痛点程度 | 高 / 中 / 低 |
| 资产目标 | 产品路线图 / 能力底账 / 新发现的限制 / 销售打法 |

### 1.5 合格线书写格式

```
结构：必填字段 / 枚举合法 / 行数下限 / 覆盖率
证据：来源要求（哪些字段必须带来源、哪些必须 T1/T2）/ 允许 C 级比例
结论：用户拍板项（仅 D 表）
```
