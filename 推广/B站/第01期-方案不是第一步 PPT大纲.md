### 第2页 · 场景认知：同一套 PLC 采集，换个行业就不成立

**页面目标**：让观众明白"产品通用"是幻觉——同一功能在不同行业的门槛完全不同，所以第一件事是把场景的行业属性查清。

**核心内容**：
- 左：同一套 PLC 采集，两个场景的硬要求不同（普通工业厂房：实时性、可靠性；燃气场站：防爆等级）
- 判断：这层差异没识别出来，大概率项目失败
- 右：要查六样——技术门槛、商业门槛、合规门槛、强制准入标准与认证、当前主要供应商与头部、场景由哪些设备组成及相互怎么协作
- 底：有了这些认识，才能判断"我的产品能不能成为这个方案的一部分"

**关键文字素材**：
- 对比卡 A：普通工业厂房 → 实时性、可靠性
- 对比卡 B：燃气场站 → 防爆等级
- 中间标记：≠（换个行业，同一套方案不成立）
- 六项清单：技术门槛 / 商业门槛 / 合规门槛 / 准入标准与认证 / 供应商与头部 / 设备组成与协作
- 底部结论条：产品能不能用，不由功能决定，由行业的门槛决定

**关键证据**：本页只用定性对比，**不引用具体防爆标准号**（与口播口径一致）。若后续要上标准号（如 GB 3836 系列），必须先补出处再上屏，否则保持"防爆等级"这一表述。

**观点型标题**：产品能不能用，不由功能决定，由行业的门槛决定

### 第3页 · 商业规则：先看这个场景卖多少钱，再看你的成本

**页面目标**：让观众意识到"这个场景卖多少钱"是硬约束——成本结构进不去的场景，产品再好也没用。

**核心内容**：
- 同一块手持终端/平板，价格从五六百到一万以上
- 成本两千的机器放进教育或会议室场景，不是"贵一点"，是根本不成立
- 这不是质量问题，是商业结构问题：教育看预算走量，会议室看品牌与生态
- 还要查四样：上下游、供应链利润分配、竞争对手、行业技术与市场发展

**关键文字素材**：
- 价格轴：500 元 ←——————→ 10000 元以上
- 定位标记：成本 2000 的平板（落在轴左侧约 1/5 处）
- 两张场景卡：教育场景（预算敏感、走量）/ 会议室场景（品牌、生态）
- 一句判断：不是贵一点，是根本不成立
- 四项清单：上下游 / 利润分配 / 竞争对手 / 行业趋势

**关键证据**：价格区间取自本期口播案例（五六百到一万以上）。**发布前二选一**：① 补一次公开报价出处（电商在售价或招标价）并在页脚标注来源；② 改为量级表述"从几百到上万，差一个数量级"。二者都不做则不上具体数字。

**观点型标题**：场景能不能进，先看这个场景卖多少钱

**视觉**：
- 类型：价格轴 + 场景卡矩阵（03_content_data_card 变体）
- 布局：上 15% 标题；中 25% 横向价格轴；中下 30% 两张场景卡左右并排；下 20% 四项清单横排；下 10% 结论句
- 具体元素：
  - 价格轴：深蓝水平线 4px，两端圆点；左端标签"500 元"、右端"10000 元以上"，16px 深蓝
  - 定位标记：橙色 #FF9800 竖线 3px + 顶部标签"成本 2000 的平板"，落在轴左侧约 1/5 处，14px
  - 场景卡 ×2：白底、科技蓝边框、18px 标题 + 14px 说明，左右各占 45%
  - 四项清单：四个浅蓝底 #E3F2FD 小标签横排，14px
  - 结论句：橙色三角标记 + 20px 深蓝加粗字
- 字体：价格数字 DIN Bold 48px；其余思源黑体 Bold 34px / Regular 18px

### 第4页 · 三道门都过了，才轮到谈产品价值

**页面目标**：让观众记住一个顺序——先过三道门（有钱赚、没壁垒、有竞争力），再谈价值，最后才搭架构。

**核心内容**：
- 三道门并列、缺一不可：场景有钱赚 / 没有进入壁垒 / 手上的产品有竞争力
- 过了才谈"真实价值"：不是"我们能做"，是"客户愿意为它掏钱"
- 价值要逐条对：解决什么问题 / 扮演什么角色 / 与谁协作 / 比竞品强在哪（功能全？性能优？成本低？）
- 最后才是：搭架构、算成本、定计划

**关键文字素材**：
- 三道门：有钱赚 / 没壁垒 / 有竞争力
- 通过标记：三条全部打勾才放行
- 价值四问：解决什么 / 什么角色 / 跟谁协作 / 强在哪
- 顺序链：三道门 → 产品真实价值 → 解决方案（架构 / 成本 / 计划）
- 警示句：顺序反了，方案就会替自己找理由

**关键证据**：本页论点是"顺序即方法"——方案一旦先写，就会倒过来挑对自己有利的材料（口播第 4 页的因果说明）。属方法论证，用流程链表达，无需外部数据。

**观点型标题**：先过三道门，再谈产品价值，最后才是方案

**视觉**：
- 类型：门禁流程链（流程图变体）
- 布局：上 15% 标题；中 35% 横向三段链（三道门 → 价值四问 → 方案）；中下 30% 价值四问 2×2 四宫格；下 20% 警示条
- 具体元素：
  - 三道门：三个圆角方块，蓝色系深浅交替（深蓝 #0D47A1 → 科技蓝 #1565C0 → 浅蓝 #E3F2FD，浅蓝块用深蓝字），每块右上角绿色 #4CAF50 对勾
  - 箭头：深蓝 3px，箭头上方标注"全部通过"，14px
  - 价值四问：2×2 四宫格，白底、科技蓝边框 2px、18px 深蓝字
  - 方案段：橙色 #FF9800 边框 2px，标注"最后一步"，内含三个小标签"架构""成本""计划"
  - 警示条：白底 + 左侧橙色竖条 6px，20px 深蓝加粗
- 字体：思源黑体 Bold 34px / Regular 18px；标签 14px
